# Romantic Age — Phase 1 Project Rules

## Project scope

This phase establishes the folder structure and a barebones site layout. Do not write the literary analysis or other finished work content yet, and do not add complex animations.

## Stack and implementation rules

- Build with Astro, plain CSS, and vanilla JavaScript.
- Do not use React, Tailwind, a backend, or a database.
- Use semantic HTML and make the site mobile-friendly.
- Respect the user's `prefers-reduced-motion` setting.
- Keep pages and components organized, clean, and well commented.

## Required sections for each work

When content is added in a later phase, each work must include:

1. Author
2. Time/era/context
3. Summary
4. Analysis
5. Themes/Motifs
6. Symbols
7. Conventions
8. References/Conclusion
9. Resonance today

## Works covered

- *Annabel Lee*
- *The Cask of Amontillado*
- *I Wandered Lonely as a Cloud* (also known as *Daffodils*)
